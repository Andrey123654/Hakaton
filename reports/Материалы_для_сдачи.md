## Как воспроизвести за 5 минут

```bash
git clone https://github.com/Andrey123654/Hakaton
cd Hakaton
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/jupyter nbconvert --to notebook --execute --inplace \
    notebooks/best_solution_0.996062.ipynb
```

Ожидаемый результат: **OOF F1 = 0.99194**, файл `submission_from_notebook.csv`.
Тетрадка не обращается к сети: используются сохранённые снимки внешних данных.

## Важные оговорки

1. **Сетевые признаки временны́е.** Они описывают состояние домена на момент
   запроса (резолвится ли он, есть ли TLS, что отдаёт HTTP, возраст регистрации
   по RDAP, ASN и возраст IP-префикса). Внутри соревнования это корректно:
   обучающая и тестовая выборки собраны в один период, публичная и приватная
   части — случайные подмножества одного теста; правила разрешают сторонние
   данные. Для потоковой детекции «здесь и сейчас» признак не переносится —
   там домен атаки ещё жив. Поэтому в репозитории сохранены снимки, и результат
   воспроизводится из них детерминированно, без повторных запросов в сеть.
2. **Небольшое расхождение с загруженным файлом.** Тетрадка воспроизводит
   конвейер на актуальных снимках и отличается от `submission_net_full.csv`
   (sha256 `493b4d984d6c80ef…`) в 18 строках из 16 000: снимок RDAP был позже
   дополнен повторным опросом 896 доменов после троттлинга реестров. Оценка
   качества при этом не меняется (OOF F1 = 0.99194 против 0.99195).
3. **Независимая проверка.** Соответствие «код → файл → загрузка → оценка»
   зафиксировано в `reports/Проверка_соответствия_решений.md` с контрольными
   суммами загруженных файлов.
