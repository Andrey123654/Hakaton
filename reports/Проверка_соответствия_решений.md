## V6: проверка гипотезы об усилении рефита

`improved_v6/submission_v6_main.csv` — усреднение трёх моделей V1, обученных на
полной выборке (seeds 42, 43, 44), смешанное с V2 с **весом 0.25** (в V5 вес был
0.1). Публичный результат — **0.994420**, то есть на 0.00066 хуже V5-refit.
`improved_v6/submission_v6_alternative.csv` побайтово совпадает с
`submission_v5_refit.csv`, поэтому отдельным решением не является.

Вывод: увеличение веса рефита не улучшает результат — гипотеза отклонена.

## Почему публичный рейтинг не различает эти решения

Публичная часть — 20 % теста (3200 адресов). Стандартная ошибка оценки F1 при
F1 ≈ 0.995 на такой выборке равна **0.00125**, а одно изменённое предсказание
сдвигает F1 примерно на **0.0004**.

| Решение | Публичный F1 | Отличие от лучшего |
|---|---|---|
| V5-refit | 0.995076 | — |
| V2 / V3 | 0.994747 | −0.00033 (≈1 объект) |
| V4 | 0.994746 | −0.00033 |
| V6-main | 0.994420 | −0.00066 (≈2 объекта) |
| V4-alternative | 0.994418 | −0.00066 |

Весь наблюдаемый разброс (0.00066) меньше одной стандартной ошибки публичной
оценки. Это означает, что публичный рейтинг не позволяет надёжно упорядочить
решения внутри этой группы, и дальнейшие загрузки вариантов с весами смесей
дают информацию о шуме, а не о качестве. Приватная часть (12 800 адресов)
разрешает примерно вдвое меньшие различия, поэтому для неё важнее не выбор
между вариантами одной семьи, а наличие решения с подтверждённым качеством на
отложенных данных.

Важно: рефиты V5/V6 не имеют независимой оценки на отложенной выборке —
их вес подобран эвристически. Различия в 3–10 ответов из 16 000 на публичной
части (3200 адресов) дают разброс F1 около 0.0003–0.0010, что лежит в пределах
стандартной ошибки публичной оценки (≈ 0.0014). Поэтому выбор между V2, V4 и
V5-refit для приватного рейтинга — вопрос хеджирования, а не точного
ранжирования.

## Рекомендация для приватного рейтинга

Отметить два решения:

1. `improved_v5/submission_v5_refit.csv` — лучший подтверждённый публичный
   результат (0.995076);
2. `improved_v4/submission_v4.csv` — лучший результат с независимой
   кросс-валидацией (OOF F1 = 0.99041), то есть наиболее надёжная оценка
   качества на невиданных данных.
